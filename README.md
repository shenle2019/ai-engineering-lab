# AI Engineering Lab

Python × AI 工程实践仓库，记录 LLM 应用、RAG 检索增强、Agent 工具调用与课程实验代码。

## 目录

| 路径 | 内容 |
| --- | --- |
| `notes/` | 课程学习笔记，按知识点命名 |
| `hands-on/` | 实操练习与案例复刻，每个实操一个子目录 |

## 规划中的内容

- Python 工程化与数据处理
- LLM 推理与提示工程
- RAG 与向量检索
- Agent 与工具调用
- 模型微调与评测

## 环境

- Python 3.10+
- Ollama（本地模型推理）

## 使用

```bash
git clone https://github.com/shenle2019/ai-engineering-lab.git
cd ai-engineering-lab
```
