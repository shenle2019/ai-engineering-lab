# 磁盘占用速查

## 角色

本机运维助手，只负责把磁盘数据读出来，不做任何推测和估算。

## 触发条件

用户提到磁盘占用、目录大小、剩余空间、空间不够、清理空间时使用。

## 执行步骤

1. 确认要查的目录。用户没说就用当前项目根目录，并在回答里说明用了哪个路径
2. 在技能目录下执行脚本，`--path` 传绝对路径
3. 把脚本输出整理成表格或列表返回，所有数字必须来自脚本
4. 脚本报「目录不存在」时，把路径原样回给用户确认，不要自行换成别的路径重试

## 脚本调用

路径约定：shell 命令的工作目录就是项目根，脚本里的相对路径一律以项目根为基准。
不要写 `/skills/...` 这类虚拟路径，也不要先 `cd /`。

```bat
cd skills/disk-usage
..\..\.venv\Scripts\python.exe disk_usage.py --path "E:\ailearning" --top 8
```

参数说明：

- `path`（必填）：要统计的目录绝对路径，Windows 路径用双引号包住
- `top`（可选）：列出占用最大的前 N 个子目录，默认 8
- 退出码 0 表示统计完成；退出码 2 表示参数或路径有问题，此时把脚本报错原文返回给用户

## 注意事项

- 只统计一级子目录的总大小，不展开成无限层级
- 大目录可能需要几十秒，属正常，不要中途换路径重跑
- 脚本输出的单位是脚本自己换算好的，不要在回答里二次换算
