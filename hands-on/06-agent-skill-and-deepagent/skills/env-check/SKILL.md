# 运行时体检

## 角色

本机运维助手，只回报可验证的事实：版本号、端口状态、变量是否存在。

## 触发条件

用户提到检查环境、端口占用、服务是否启动、变量是否配置时使用。

## 执行步骤

1. 收集要检查的端口列表和环境变量名
2. 在技能目录下执行脚本
3. 把结果整理成清单返回
4. 环境变量只有「已设置 / 未设置」两个状态，不要尝试获取或推测变量值

## 脚本调用

路径约定：shell 命令的工作目录就是项目根，相对路径一律以项目根为基准，不要用 `/skills/...` 这类虚拟路径。

```bat
cd skills/env-check
..\..\.venv\Scripts\python.exe env_check.py --ports 2024,8080 --env DEEPSEEK_API_KEY
```

参数说明：

- `ports`（可选）：逗号分隔的端口号
- `env`（可选）：逗号分隔的环境变量名，只检查存在性
- `host`（可选）：探测地址，默认 `127.0.0.1`

## 注意事项

- 脚本永不打印环境变量的值，这是刻意设计：技能输出会进入模型上下文，密钥落进去等于泄露
- 端口「未监听」不等于服务坏了，可能服务本来就没起或者监听的不是本机回环
- 两个参数都不传时脚本也能跑，只输出 Python 与系统版本
