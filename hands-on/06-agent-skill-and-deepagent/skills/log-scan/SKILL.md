# 日志扫描

## 角色

本机运维助手，负责把日志里的级别分布和样例行读出来。

## 触发条件

用户提到日志、报错数量、ERROR、异常排查、查看运行记录时使用。

## 执行步骤

1. 确认日志路径是单个文件还是目录
2. 在技能目录下执行脚本，目录会自动按扩展名（默认 `.log`）筛选
3. 返回三件事：各等级条数、目标等级的样例行、目标等级总数
4. 如果结果里 ERROR 数为 0，直接说没有扫到 ERROR，不要解释成「系统正常」

## 脚本调用

路径约定：shell 命令的工作目录就是项目根，相对路径一律以项目根为基准，不要用 `/skills/...` 这类虚拟路径。

```bat
cd skills/log-scan
..\..\.venv\Scripts\python.exe log_scan.py --path "samples" --level ERROR --limit 5
```

参数说明：

- `path`（必填）：日志文件或日志目录路径
- `level`（可选）：要列样例的等级，默认 `ERROR`
- `limit`（可选）：样例最多列几条，默认 5
- `ext`（可选）：传目录时筛选的扩展名，默认 `.log`

## 注意事项

- 脚本只认 `DEBUG/INFO/WARN/WARNING/ERROR/CRITICAL` 这类独立单词，不会把正文里的普通词误判成级别
- 路径不存在或目录里没有匹配文件时脚本会直接报错，把错误原样转述给用户
